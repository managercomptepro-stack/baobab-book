# Baobab Book — mise en route

1. Clé GitHub : github.com → Settings → Developer settings → Fine-grained tokens → Generate. Dépôt : **baobab-book**. Permission **Contents : Read and write**.
2. Ouvre `/gestion/` sur le site, colle la clé, puis va dans **Réglages** et saisis ton numéro WhatsApp (ex. 237699112233).
3. Site gratuit tout de suite : dépôt GitHub → Settings → Pages → Branch **main** / root → Save. Adresse : `https://managercomptepro-stack.github.io/baobab-book/`.
4. Hébergeur classique : copie tout le dossier dans `public_html` (le `.htaccess` gère HTTPS et le cache).
5. Chaque modification faite dans `/gestion/` est en ligne en environ 1 minute, sans rien redéployer.
6. Lien direct à partager sur Facebook : `…/#livre-12` (livre n°12) ou `…/#pack-P001` (bouton « Copier le lien » dans la gestion).
